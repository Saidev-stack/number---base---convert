# Number Base Converter
Project completed as part of my programming apprenticeship

# Descreption
This programme allows to convert numbers between the different bases :
- Binary
- Octal
- Decimal
- Hexadecimal

The conversion algorithms were implemented manually without relying on Python built-in functions such as bin(), oct(), or hex()
